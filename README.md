# AYOUB LAOUQID — Google Sites Portfolio Kit
## What is included
- `preview/index.html`: a responsive visual reference for the complete portfolio. Open it in a browser to preview the design.
- `google_sites_content/website_copy.md`: editable page copy and section content.
- `google_sites_content/build_guide.md`: step-by-step instructions for recreating the site in Google Sites.
- `visual_assets/`: colour palette and asset checklist.

## Important
This is a design and content kit, not a one-click Google Sites import file. Google Sites does not import a complete HTML site as an editable Google Sites template. Use the HTML preview as a visual reference and recreate its sections with Google Sites' built-in layouts, text, images, buttons and embeds.

## Before publishing
Replace the email and LinkedIn placeholders, add a professional portrait if desired, insert real project examples and links, check permissions for all client work, and proofread names, dates and claims.
