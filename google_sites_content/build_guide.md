# Google Sites build guide

## 1. Create the site
1. Visit https://sites.google.com/new/
2. Choose **Blank**.
3. Name the site `AYB | Journalism & Communications`.
4. In the Pages tab, create: Home, About, Expertise, Journalism, Communications, Contact.
5. Set the navigation to the top.

## 2. Apply the visual identity
Use a restrained institutional palette:
- Deep navy: `#14263D`
- Warm white: `#F7F7F4`
- Slate grey: `#687482`
- Muted gold: `#B49A68`
- Light divider: `#DFE3E6`

Choose a clean theme. Use a serif display font for major headings if the theme offers one, and a highly readable sans-serif font for body copy. Keep headings consistent.

## 3. Build the Home page
- Add a large banner with a dark navy background.
- Add the headline: “Journalism. Communication. Digital content.”
- Add the short introduction from `website_copy.md`.
- Add two buttons: “Explore my work” (link to Communications) and “Get in touch” (link to Contact).
- Add a three-project featured section below the banner.

## 4. Build the remaining pages
Use the copy in `website_copy.md`. Use Google Sites **Insert → Layouts** to create alternating text-and-image rows. Keep paragraphs short and leave generous white space.

## 5. Add work samples
For each selected project, include:
- Project title and year
- Client/institution, only if you are authorized to disclose it
- Objective or context
- Your exact contribution
- Deliverable (article, video, carousel, press file, event coverage)
- Link to the published output, or an embedded video/document

Use **Insert → Drive** for Google Drive files, **Embed** for supported public links, and image blocks for approved visuals.

## 6. Add your CV
Upload your CV PDF to Google Drive, set appropriate sharing permissions, then add a button on Home and Contact linking to the PDF.

## 7. Publish and test
1. Click **Publish** and choose a short web address.
2. Check the published site on desktop and mobile.
3. Test every navigation link, button, video and CV link.
4. Check spelling, dates, titles and permissions before sharing.

## Content and privacy checklist
- Replace `your.email@example.com` and the LinkedIn placeholder.
- Add only genuine project examples.
- Do not publish confidential drafts, internal documents, unpublished campaign plans or client material without permission.
- Credit collaborators where appropriate.
- Avoid implying that you led or authored work that was produced by a team.
- Keep the portfolio selective: a small number of strong examples is better than a large archive.
